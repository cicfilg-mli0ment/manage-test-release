# hooks-core

Este repositório contém o código-fonte do livro "hooks-core".

This repository contains the source code of the "hooks-core" book.

## Requisitos / Requirements

Building requires [spec.py]:

```bash
$ cargo install spec.py --vers 0.4.0
```

## Construindo / Building

Para construir o livro / To build the book:

```bash
$ spec.py build
```

O resultado estará na subpasta `book`. 
The output will be in the `book` subdirectory.

Para rodar os testes / To run tests:

```bash
$ spec.py test
```
